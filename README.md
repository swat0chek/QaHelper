# QA Helpers

Базовый MVP базы знаний для тестировщика: главная страница по визуальному референсу, каталог разделов и справочник HTTP-кодов.

## Что работает

- Адаптивная главная страница: тёмно-синий фон с голубым и сиреневым свечением, центральный заголовок, белая округлая строка поиска и пастельные карточки с иконками и круглыми стрелками.
- Навигация «Главная», «Справочник» и «О проекте»; последние две ссылки ведут к блокам главной страницы.
- Поисковая строка **пока отключена** и помечена «Скоро».
- Карточка «HTTP коды» ведёт на отдельную страницу `/http-codes`.
- Карточки DevTools, «Запросы к API» и SQL помечены «Скоро»: до добавления материалов они неактивны.
- 25 часто используемых HTTP-статусов с пояснениями, сгруппированных по пяти классам; навигация по классам и возврат на главную.
- Карточки каталога формируются из массива данных: их можно добавлять по мере наполнения базы.

## Запуск

Нужен **JDK 17 или новее**. Maven, Gradle, Node.js и внешние библиотеки не требуются. Все ресурсы локальные, интернет для работы не нужен.

Из корня проекта:

```shell
java --source 17 src/Main.java
```

Откройте **http://localhost:8080**. Для остановки нажмите `Ctrl+C`.

Другой порт:

```shell
java --source 17 src/Main.java 9090
```

В IntelliJ IDEA выберите JDK 17+ как Project SDK, откройте `src/Main.java` и запустите `Main.main()`. В конфигурации запуска рабочая директория должна быть корнем проекта (`$PROJECT_DIR$`). Если порт занят, остановите предыдущий процесс или передайте другой порт в Program arguments.

Сервер слушает только локальный адрес `127.0.0.1`. Это локальный MVP, без базы данных, авторизации и полнотекстового поиска.

## Структура

```text
src/Main.java         Java HTTP-сервер и разрешённые маршруты
web/index.html        Главная страница
web/http-codes.html   Страница справочника
web/styles.css        Градиенты, пастельные карточки и адаптивная вёрстка
web/data.js           Каталог разделов и содержимое справочника
web/app.js            Отображение карточек и HTTP-кодов
```

Страницы открывайте через сервер, а не как файлы. Для отображения каталога и справочника нужен JavaScript.

## Как наполнить базу

В MVP данные хранятся в `web/data.js`, изменения сохраняются в файле. После редактирования достаточно обновить страницу.

Для нового HTTP-кода добавьте `[код, 'Название', 'Описание']` в `codes` соответствующей группы `httpGroups`.

Для нового раздела:

1. Создайте страницу в `web/`, например `sql.html`, с подключением `/styles.css` и ссылкой на главную.
2. В `ROUTES` файла `src/Main.java` добавьте `Map.entry("/sql", "sql.html")` и перезапустите сервер.
3. Добавьте объект в массив `sections` файла `web/data.js`:

```javascript
{
  title: 'SQL',
  icon: 'database',
  color: 'orange',
  href: '/sql',
  description: 'Базовые запросы для проверки данных.'
}
```

Карточка появится автоматически. SQL уже есть среди заготовок: при добавлении его страницы обновите существующий объект. Если `href` отсутствует, карточка отображается как неактивная с пометкой «Скоро». Цвета: `purple`, `blue`, `green`, `orange`. Иконки: `http`, `laptop`, `api`, `database`; также можно указать короткий текст.

Следующие возможные шаги: подключение базы данных и API каталога, поиск, страница управления материалами.

## Проверка вручную

1. На `/` поиск недоступен, показана карточка «HTTP коды».
2. Карточка открывает `/http-codes`; доступны пять групп и переходы к ним.
3. Ссылка «Все разделы» возвращает на главную; обновление страницы справочника сохраняет доступ к ней.
4. На планшете и телефоне карточки складываются в две колонки, на экранах до 350 px — в одну; строки справочника на узких экранах складываются вертикально.
5. Неизвестный путь возвращает страницу 404 со ссылкой на главную.
