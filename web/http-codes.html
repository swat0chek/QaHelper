HTTP Status Code Finder

Найдите статус по коду или проблеме. Разберитесь в ответе и выберите следующие проверки.

i

Первая цифра определяет класс ответа: 1xx — информация, 2xx — успех, 3xx — перенаправление, 4xx — ошибка клиента, 5xx — ошибка сервера.

Ищет по словам и распространённым описаниям проблем. Статус помогает выбрать проверки, но не доказывает причину ошибки.
